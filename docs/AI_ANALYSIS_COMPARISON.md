```markdown
### 📋 攻擊描述
透過大量請求耗盡目標系統資源，使正常用戶無法訪問服務

### 🔍 關鍵特徵分析
- **Flow Byts/s**: `5000000.00`
  🌊 流量速率極高（可能為頻寬消耗攻擊）
- **Tot Fwd Pkts**: `15000.00`
  📦 封包數量異常龐大（可能為 DDoS 或資料傳輸）
- **Tot Bwd Pkts**: `12000.00`
  📦 封包數量異常龐大（可能為 DDoS 或資料傳輸）
- **Flow Pkts/s**: `8000.00`
  📦 封包數量偏高
- **Flow Duration**: `1500.50`

### 📊 典型攻擊指標
- 異常高的封包數量 (Tot Fwd Pkts, Tot Bwd Pkts)
- 短時間內大量連線 (Flow Duration 短但流量大)
- 高流量速率 (Flow Byts/s, Flow Pkts/s)
- 重複的源 IP 或目標 IP

### ⚠️ 潛在風險
🔴 服務中斷，影響業務連續性
🔴 伺服器資源耗盡
🟡 可能掩蓋其他攻擊行為
🟡 品牌聲譽受損

### 💡 處理建議
1. 立即啟動 DDoS 防護機制（如 CDN、Anti-DDoS 服務）
2. 限制單一來源的連線速率
3. 使用負載均衡分散流量
4. 監控異常流量模式並自動封鎖
5. 聯繫 ISP 協助過濾惡意流量

---
*📌 此分析基於機器學習模型預測和領域知識規則，建議結合實際情況和專業資安團隊進行判斷。*
```

**優點**:

- ✅ 智能的特徵異常分析

## 🔬 智能特徵分析

新版本會根據特徵值自動判斷異常程度：

### Flow Duration（連線時長）
- `< 1000` → ⚡ 極短連線時間（掃描/快速攻擊）
- `> 1000000` → 🕐 異常長連線（資料竊取）

### Packet Count（封包數）
- `> 10000` → 📦 封包數量異常龐大
- `> 1000` → 📦 封包數量偏高

### IAT（封包間隔）
- `< 10` → ⚡ 封包間隔極短（高速攻擊）
- `> 100000` → 🕐 封包間隔極長（慢速攻擊）

### Traffic Rate（流量速率）
- `> 1000000` → 🌊 流量速率極高（頻寬攻擊）
